PHP API Gateway - Documentation

All requests require a valid API key passed as a header: X-API-Key

Endpoints

  • GET /api/users
    Returns a list of users.
    Sample: [{"id":1,"name":"Alice"}]
  • GET /api/products
    Returns a list of products.
    Sample: [{"sku":"A123","productName":"Samsong"}]

Error Codes

  • 401 - Invalid or missing API key
  • 429 - Rate limit exceeded
  • 404 - Endpoint not found
